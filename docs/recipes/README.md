# Task recipes

Each recipe has the problem, a prompt to paste into your agent, the exact tool call, and real output from agentic-video 0.3.3 on the repo fixtures.

- [Cut list and average shot length](cut-list-shot-length.md): list every cut and work out the average shot length.
- [Find where something is said](find-spoken-words.md): find the timecode of a spoken phrase.
- [Check audio/video sync](check-audio-sync.md): check that sounds land within the tolerance of their cue times.
- [Read on-screen text at a moment](read-on-screen-text.md): get one frame at full size and read the text on it.
- [Count things crossing the frame one way](count-one-way-crossings.md): count separate appearances that move one way.
- [Timestamped contact sheet for a long video](contact-sheet-long-video.md): one grid of evenly spaced, timestamped frames.
